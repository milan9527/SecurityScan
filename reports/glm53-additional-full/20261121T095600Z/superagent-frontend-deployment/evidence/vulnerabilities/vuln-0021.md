# CVE-2026-104850 in @modelcontextprotocol/sdk 1.29.0 (OAuth credential redirection to attacker-chosen MCP server)

**ID:** vuln-0021
**Severity:** MEDIUM
**Found:** 2026-11-21 10:04:24 UTC
**Target:** super-agent (agentcore runtime)
**Package:** @modelcontextprotocol/sdk
**Ecosystem:** npm
**Installed Version:** 1.29.0
**Fixed Version:** 1.31.0
**Dependency Chain:** @anthropic-ai/claude-agent-sdk@0.2.141 > @modelcontextprotocol/sdk@1.29.0
**CVE:** CVE-2026-104850
**CWE:** CWE-345
**CVSS:** 6.3
**Advisory CVSS:** 7.5
**Contextual CVSS Vector:** CVSS:3.1/AV:N/AC:H/PR:L/UI:N/S:C/C:H/I:N/A:N
**Fix Effort:** Low

## Description

The agentcore runtime pins `@modelcontextprotocol/sdk` 1.29.0 in `agentcore/package-lock.json` (transitive via `@anthropic-ai/claude-agent-sdk` 0.2.141). SDK versions 1.12.0–<1.31.0 are affected by CVE-2026-104850 (advisory CVSS 7.5): the OAuth client support lets the MCP server a client connects to decide which authorization server receives the client's OAuth credentials — stored/pre-provisioned credentials are not bound to their authorization server, so a malicious or compromised MCP server can name its own authorization server in its protected-resource metadata and, without user interaction, receive the client's refresh token.

## Evidence

**Advisory evidence:** `CVE-2026-104850` applies to `@modelcontextprotocol/sdk` at installed version `1.29.0`. The advisory is fixed in `1.31.0`.

**Dependency chain:** `@anthropic-ai/claude-agent-sdk@0.2.141 > @modelcontextprotocol/sdk@1.29.0`

**Usage analysis:** the advisory's vulnerable code runs in this codebase. Entry point: the agentcore runtime HTTP handler POST /invocations (agentcore/src/index.ts:119) parses the invocation payload, whose `mcp_servers` field (typed at agentcore/src/types.ts:19) is attacker/tenant-controlled. Intermediate call: agentcore/src/agent-runner.ts:298-299 assigns `baseOptions.mcpServers = payload.mcp_servers` into the options passed to @anthropic-ai/claude-agent-sdk 0.2.141, whose client (agentcore/package-lock.json dependency ^1.29.0) uses @modelcontextprotocol/sdk 1.29.0 as its MCP client transport. Package call: the SDK's MCP client connects to each configured server URL and performs the OAuth handling the advisory describes (protected-resource metadata deciding where credentials are sent). No allowlist or validation of mcp_servers URLs exists between payload and the SDK (agent-runner.ts:298 checks only that the object is non-empty), so the connected server is fully attacker-chosen whenever a tenant can configure an agent's MCP servers. Chain: POST /invocations payload (tenant-controlled) -> agent-runner.ts:298 baseOptions.mcpServers -> claude-agent-sdk -> @modelcontextprotocol/sdk 1.29.0 OAuth client (vulnerable sink).

## Impact

The agent runtime forwards tenant-configured `mcp_servers` into the SDK client, so a malicious or prompt-influenced MCP server entry becomes the connected server. If OAuth-based MCP authentication is used in a deployment, that server can capture the client's refresh token / credentials for the platform's authorization server — credential disclosure across a trust boundary to an attacker-controlled endpoint.

## Contextual CVSS

Entry point: POST /invocations handled by the agentcore runtime HTTP server (agentcore/src/index.ts:119) reaches agent-runner.ts:298-299, where the tenant-supplied payload.mcp_servers map is assigned verbatim into baseOptions.mcpServers of @anthropic-ai/claude-agent-sdk, which connects as an MCP client through the pinned @modelcontextprotocol/sdk 1.29.0 (agentcore/package-lock.json:1155). This is exactly the advisory's scenario: a tenant-chosen (potentially malicious) MCP server receives OAuth credentials/refresh tokens not bound to an authorization server. The chain requires the attacker to hold the ability to configure an agent's MCP server list (privileges L, an authenticated tenant operation) and for the agent runtime to use OAuth-authenticated MCP servers (complexity H — the configuration path is present, whether OAuth credentials are provisioned depends on deployment). Confidentiality H and scope C: credentials issued for the platform's authorization server would be forwarded to an attacker-controlled server, crossing the agent-runtime trust boundary. Integrity/availability N.

## Remediation

Upgrade the MCP SDK to a fixed version (>= 1.31.0, or the 2.2.0 line) by bumping @anthropic-ai/claude-agent-sdk to a release depending on it, or add an override in agentcore/package.json ("overrides": { "@modelcontextprotocol/sdk": "^1.31.0" }). Additionally, validate tenant-supplied mcp_servers URLs against an operator allowlist in agent-runner.ts before assigning them to baseOptions.mcpServers.
