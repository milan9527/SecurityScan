## 验证结论与边界

三项均完成；退出码 2 表示发现达到阈值，不是执行失败。合计 1,310 次成功流式请求、4 条待独立复核发现，不代表 4 个已确认漏洞。

- GitLab：graphql-ruby 词法解析耗时异常。组件复现中 260 字节输入耗时约 33.4 秒，对照版本约 0.038 秒；未完成完整 Rails HTTP 链路验证。
- Grafana：插件安装路径处理可越过插件目录。使用真实路由及安装器，但目录源为合成夹具；依赖管理员 plugins.install 权限及插件管理启用，生产插件目录能否接受该输入尚未验证。早期密码重置、跨组织及 CRLF 假设未成立。
- Airflow：日志追加路径问题要求同时启用 allow_double_dot_in_ids 和非默认裸 ID 日志模板，默认配置受保护；未验证任意日志读取。
- Airflow：旧版插件登录路由抛出 BuildError，属于失败关闭的兼容性/可用性问题，不是认证绕过，安全影响尚未确认。验证使用 FastAPI/FAB TestClient 和合成 SQLite，未部署完整 Breeze 环境。
