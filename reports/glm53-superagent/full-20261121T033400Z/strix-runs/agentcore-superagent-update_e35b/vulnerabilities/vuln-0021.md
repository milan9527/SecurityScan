## Description

Fastify 5.6.2 (the application's own HTTP framework, a direct production dependency) is affected by multiple published 2026 advisories: request validation bypass (CVE-2026-84469, advisory high), validation bypass via malformed Content-Type leading to integrity impact (CVE-2026-25223), schema validation bypass (CVE-2026-33806), authentication bypass via malformed URLs (CVE-2026-76169), header validation bypass (CVE-2026-84428), and unauthorized state changes/data disclosure via request body replacement (CVE-2026-84504). Fixed in Fastify 5.12.2.

## Evidence

**Advisory evidence:** `CVE-2026-84469` applies to `fastify` at installed version `5.6.2`. The advisory is fixed in `5.12.2`.

**Transitive dependency:** introduced by the direct dependency `fastify@5.6.2`.

**Dependency chain:** `fastify@5.6.2`

**Usage analysis:** the advisory's vulnerable code runs in this codebase. fastify is the application framework itself: src/app.ts:58 `Fastify({...})`, binds default HOST 0.0.0.0 (src/config/index.ts:12) and serves all routes registered in src/routes/index.ts. Every unauthenticated network request (including to unauthenticated routes like /health, /api/im/*, widget, OAuth callback) is parsed and validated by this exact Fastify version — the vulnerable parsing/validation code executes on the attacker-reachable path.

## Impact

Request-validation and authentication-layer bypasses in the framework that fronts every API route, enabling unauthorized operations and potential data disclosure; also DoS vectors in the router (find-my-way 9.4.0 CVE-2026-47219) and multipart parser (@fastify/busboy 3.2.0, CVE-2026-19481/19484) reachable from unauthenticated request surfaces.

## Contextual CVSS

The backend's own HTTP framework is Fastify 5.6.2, mounted at HOST 0.0.0.0. The known Fastify validation-bypass CVEs (CVE-2026-25223, CVE-2026-33806, CVE-2026-76169, CVE-2026-84428, CVE-2026-84469, CVE-2026-84504) target request validation/parsing on the network path, so an unauthenticated network attacker reaches the vulnerable code with attacker-controlled requests. Demonstrated impact here is request-validation/DoS class (A:L, C:N, I:N) since no specific bypass payload was executed in this isolated assessment.

## Remediation

Upgrade fastify to >= 5.12.2, find-my-way (transitive, via fastify) to >= 9.7.0, and @fastify/busboy to >= 3.2.2 (pulled in via @fastify/multipart 9.4.0 used for uploads). Run npm audit / npm update and re-run integration tests.

## Assumptions

Version data from package-lock.json (offline trivy scan); reachability based on code inspection of multipart upload routes.
