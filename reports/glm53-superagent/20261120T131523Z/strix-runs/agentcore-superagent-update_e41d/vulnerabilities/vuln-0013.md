## Description

`fastify` 5.6.2 is pinned in `super-agent/backend/package-lock.json` and covered by advisory CVE-2026-84504 (fixed in 5.12.2). Fastify is the backend's HTTP framework and processes all inbound requests.

## Evidence

**Advisory evidence:** `CVE-2026-84504` applies to `fastify` at installed version `5.6.2`. The advisory is fixed in `5.12.2`.

**Usage analysis:** the advisory's vulnerable code runs in this codebase. Direct dependency; imported in 62 backend source files (src/app.ts, all of src/routes/*, src/middleware/auth.ts). Server construction and request handling occur in src/app.ts; the framework code runs on every HTTP request.

## Impact

All inbound HTTP traffic to the backend API is handled by the vulnerable fastify version, so any request-handling flaw in the advisory is reachable by unauthenticated callers.

## Contextual CVSS

fastify is the backend HTTP framework itself: imported in 62 files under super-agent/backend/src, starting at src/app.ts where the Fastify server is constructed and every route registered under src/routes/*. Every request to the backend reaches fastify routing and parsing code, so the advisory's server-side path executes on all unauthenticated traffic. Per-threat-model this is the product's public API surface; impact kept at the level of the advisory (request-handling flaw) with no privileged position required.

## Remediation

Bump fastify to at least 5.12.2 (fixes all six HIGH fastify advisories incl. CVE-2026-25223, CVE-2026-33806, CVE-2026-76169, CVE-2026-84428, CVE-2026-84469) and regenerate the lockfile.

## Assumptions

Static analysis; advisory details from the offline trivy DB. Multiple fastify advisories exist; this is the highest-scoring one, representative of the group.
